# 固定赛道图与视频：首次人工核对清单

目标：把当前“待验证”的参考图变成一份可复查的赛道配置，完成首个真实视频/遥测配对。
这不是官方测绘、算法准确率验收或驾驶行为真值标注。

## 先准备三样东西

1. 同一节训练的 XRK 和本地视频，并指出视频实际对应的记录仪圈号。不能只凭文件名或最像的 RPM 曲线认定配对。
2. 视频中物理计时线或其他可唯一辨认位置的一张画面，并记录视频时刻。不确定哪条线是计时线时，明确记为“未确认”。
3. 一张带弯道顺序的赛道草图，或由教练在参考图上核对。连续弯可以合并，不要求曲率候选数量等于真实弯道数量。

填写后的记录、导出的赛道 JSON、截图和视频留在本地 `tmp/manual_track_review/` 或其他私有目录，不能提交 GitHub。通用清单可以提交。

## 一、确认配对与计时线

1. 打开 **遥测分析 > 单圈分析 / Lap Analysis**，选择视频实际对应的圈，载入本地视频。
2. 保留圈号证据，例如连续过线顺序、前后圈或只出现一次的事件。只有重复弯道画面时，不排除错一整圈的可能。
3. 用一个能同时定位到视频和轨迹的位置设置人工锚点；记录采用的事件和视频时刻。
4. 再核对该圈前段、中段、后段的可辨认位置。分别记录“吻合 / 偏早 / 偏晚 / 无法判断”和可观察的时间范围。
5. 前段吻合但后段不吻合时，撤销整圈已确认的结论，保留候选和差异，等待排查错圈、锚点误差、剪辑或时间漂移。

当前人工同步是单锚点偏移。多个核对点不会自动拟合漂移，也不会被自动当成训练标签。视频几何弯心不必等于遥测最低速度点，不能直接将两者绑定为同一事件。

## 二、核对固定赛道参考图

1. 打开 **赛道图 > 固定赛道参考图 / Fixed track reference**。从一条真实、质量合格的参考圈建图，或导入同一份已有配置。
2. 使用 **定位起终点 / Place start / finish** 放置计时门，核对行驶方向。只在有视频证据时勾选“已通过视频确认计时线”。
3. 按行驶顺序检查候选区间，填写弯道名称。名称可用 T1、T2 等；内部 ID 保持稳定，不把候选编号冒充官方编号。
4. 用 **入口门 / Entry** 和 **出口门 / Exit** 调整区间。出口应覆盖要观察的恢复与出弯段，且不与下一弯重叠。
5. 连续弯需要合并时，保留一个区间，延伸其入口/出口，删除多余候选。不要跨越计时线接缝。
6. 核对完成才勾选“已核对编号与入口 / 出口”，然后点击 **匹配当前 Session**。每次改门或名称后都要重新匹配。
7. 检查每圈穿门次数、被拒绝的圈及原始 GPS。对不通过的圈保留原因，不通过放宽阈值来凑覆盖率。
8. 使用保存图标保存到当前浏览器，并导出配置 JSON。跨 Session 验证必须复用这份配置，不能每次重新自动编号。

网页目前只保存一个活跃参考图。坐标及源指纹可能具有识别性，导出的配置不要放入公开仓库。

## 三、复核运动学阶段与视频片段

- 先选一个明确的弯，分别检查一条真实快圈和一条目标圈；没有对应视频的一侧保留不可用。
- 展开 **平台圈 / 逐弯检验** 的阶段详情。返回的时间是 Session 时间，不是视频时间，也不是圈内时间。
- 区分减速、曲率建立、最低速度、再加速和出弯。没有踏板/转向传感器时，不把这些阶段确认成刹车、油门或转向输入。
- 在 **AI 教练摘要** 查看候选片段；需要修正时进入对应一侧的 **添加 / 调整片段**。仅裁剪片段不等于完成同步。
- 自动选片准确性、人工修正效果和驾驶行为确认是三个不同问题。逐项记录确认、否定或不确定及其依据。
- 目前没有统一的五阶段真值标注表单，先用私有记录表保存逐阶段结论；不要用建议的点赞替代阶段标签。

## 交回哪些结果

1. 确认采用的记录仪圈号，以及配对是已确认还是仍有疑问。
2. 计时线画面和视频时刻；前、中、后段核对记录。
3. 导出的赛道配置及弯道草图，标出待确认的组合弯。
4. 至少一个弯的阶段/片段复核记录，保留无法判断的项目。

不要求车手手算曲率或重新分析全部圈。收到这些材料后，开发者用同一配置重跑私有 Session，分别报告全部输入、通过几何门的圈、完整计时区间、穿门失败和阶段缺失，不能只报告成功子集。

## 本轮不能据此宣称

- 换计时线后，每个圈时应当与记录仪完全相同。
- 配准后的偏差就是 GPS 仪器误差，或已消除真实走线差异。
- 一个勾选、一次点赞或高相关系数证明配对/驾驶行为正确。
- 当前反馈已经可直接训练视觉模型或证明机械调校因果关系。
